## Purpose

A Rust-based terminal application and scanner designed to discover, index, and organize local comic,
manga, and webtoon libraries. It manages series and chapter metadata, tracks reading progress, and
coordinates external reader execution. The system provides an interactive terminal user interface
for browsing libraries, standardizing file structures, and synchronizing reading state.

## Domains

This system is organized into the following domains:

| Domain | Description | Spec |
|--------|-------------|------|
| App | Manages core application state, coordinates library scanning, filtering, and navigation for series and chapters. | [spec.md](../app/spec.md) |
| Db | Manages persistent storage, reading progress tracking, series and chapter metadata, and bookmarking using an SQLite backend. | [spec.md](../db/spec.md) |
| Runner | Manages execution of the external Continuum reader process, constructing execution commands, spawning reader sessions, and parsing exit progress payloads. | [spec.md](../runner/spec.md) |
| Scripts | Standardizes comic and manga series directory names and chapter filenames in the Dewey library, ensuring consistent naming schemas and updating references in the Dewey database. | [spec.md](../scripts/spec.md) |
| Ui | Encapsulates rendering and layout logic for terminal user interface components, including list views, details, modals, action bars, and status displays. | [spec.md](../ui/spec.md) |

## Requirements

### Requirement: SystemCapabilities

The system SHALL provide the following capabilities:
- Monolithic Rust design combining scanner daemon logic, TUI management, and database orchestration in a single executable
- Delegation of specialized reading and remote catalog lookup to external binaries (Continuum and Labrador) via dedicated runner abstractions rather than embedded dependencies
- SQLite chosen for primary local relational persistence with a supplementary JSON file fallback for debug reading history
- Asynchronous event loop coordinating user keystrokes, periodic timers, and background scanning tasks without blocking the UI
