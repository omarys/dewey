# Scripts Specification

> Generated by openlore v1.2.0 on 2026-10-07 15:05

## Purpose

Standardizes comic and manga series directory names and chapter filenames in the Dewey library,
ensuring consistent naming schemas and updating references in the Dewey database.

## Requirements

> `scripts/standardize_library_names.py`

### Requirement: LoadDeweyConfig

The system SHALL read dewey configuration settings from disk to determine default library directories and database paths.

- **Implementation**: `load_dewey_config::scripts/standardize_library_names.py`

#### Scenario: ConfigFileExists
- **GIVEN** A valid Dewey config.toml file exists at the default config path
- **WHEN** load_dewey_config is called
- **THEN** Configuration values for library directory and database path are returned

#### Scenario: ConfigFileMissing
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** No config.toml exists at the default config location
- **WHEN** load_dewey_config is called
- **THEN** Default fallback paths for library directory and database are returned

### Requirement: GetSeriesTitle

The system SHALL determine the canonical title of a series by inspecting directory metadata json files or falling back to the directory name.

- **Implementation**: `get_series_title::scripts/standardize_library_names.py`

#### Scenario: MetadataJSONPresentWithTitle
- **GIVEN** A series directory containing a metadata JSON file with valid title information
- **WHEN** get_series_title is called with the directory path
- **THEN** The stripped series title from metadata is returned

#### Scenario: MetadataJSONMissingOrLacksTitle
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** A series directory without metadata JSON or with empty title fields
- **WHEN** get_series_title is called with the directory path
- **THEN** The series title derived from the cleaned folder name is returned

### Requirement: TransformFilename

The system SHALL parse and normalize a chapter or volume filename into standard naming format matching the series title.

- **Implementation**: `transform_filename::scripts/standardize_library_names.py`

#### Scenario: FilenameMatchesChapter/volumePattern
- **GIVEN** A valid chapter file name needing normalization and a series title
- **WHEN** transform_filename is called
- **THEN** A standardized filename containing series title, chapter/volume numbering, and subtitle is returned

#### Scenario: FilenameAlreadyStandardizedOrUnsupported
- **GIVEN** A filename with an unsupported extension or non-matching chapter pattern
- **WHEN** transform_filename is called
- **THEN** None is returned to indicate no renaming required

### Requirement: StandardizeLibrary

The system SHALL execute the end-to-end library naming standardization workflow, updating filenames on disk and synchronizing records in the sqlite database.

- **Implementation**: `main::scripts/standardize_library_names.py`

#### Scenario: DryRunExecution
- **GIVEN** Command line arguments specifying dry run mode
- **WHEN** main is executed
- **THEN** Planned file renames and database updates are previewed without modifying disk or database

#### Scenario: ApplyRenamesAndUpdateDatabase
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** Standardization execution with write permissions
- **WHEN** main is executed
- **THEN** Files are renamed on disk, database backup is created, and chapter file paths in the database are
updated and committed
