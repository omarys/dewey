## Purpose

Manages persistent storage, reading progress tracking, series and chapter metadata, and bookmarking
using an SQLite backend.

## Entities

### Series

> `src/db/schema.rs`

Represents a manga, comic, or webtoon series containing multiple chapters.

**Properties:**

| Name | Type | Description |
|------|------|-------------|
| id | integer | Unique identifier for the series |
| title | string | Title of the series |
| sort_title | string | Normalized title used for sorting |
| cover_path | string | Local filesystem path to the series cover image |
| status | string | Publication or tracking status of the series |
| fetch_url | string | Remote URL where the series metadata or updates are fetched from |
| metadata_json | string | Serialized JSON string containing arbitrary series metadata |
| reading_mode | string | Reading display mode for the series, defaults to 'webtoon' |
| is_hidden | boolean | Flag indicating if the series is hidden from normal library views |
| category | string | Category or genre classification for the series |
| chapters_checked_at | string | Timestamp indicating when chapters were last checked for updates |

**Relationships:**

- has-many Chapter (A series contains multiple chapters)

### Chapter

> `src/db/schema.rs`

Represents an individual chapter belonging to a series.

**Properties:**

| Name | Type | Description |
|------|------|-------------|
| id | integer | Unique identifier for the chapter |
| series_id | integer | Foreign key reference to the parent series |
| chapter_number | number | The sequential number or fractional identifier of the chapter |
| file_path | string | Local filesystem path to chapter pages or archive |
| page_count | integer | Total number of pages in the chapter |
| fetch_url | string | Remote URL where the chapter was fetched from |
| is_bookmarked | boolean | Indicates whether the user bookmarked this chapter |

**Relationships:**

- belongs to Series (Chapter belongs to a specific series)
- has-one Progress (Chapter tracks reading progress in a 1-to-1 relationship)

### Progress

> `src/db/schema.rs`

Tracks the reading state, last read page, and completion status of a chapter.

**Properties:**

| Name | Type | Description |
|------|------|-------------|
| chapter_id | integer | Foreign key reference and primary key identifying the chapter |
| last_page_read | integer | The index/number of the last read page |
| is_completed | boolean | Whether the chapter has been finished |
| last_read_at | string | Timestamp when the chapter was last read |

**Relationships:**

- belongs to Chapter (Progress belongs to a specific chapter)

## Requirements

### Requirement: SeriesValidation

The system SHALL validate Series according to these rules:
- Title must not be null
- Is hidden defaults to 0 (false) and cannot be null
- Reading mode defaults to 'webtoon'

#### Scenario: CreateNewSeries
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** A valid series title
- **WHEN** A new series record is inserted
- **THEN** The series is persisted with default reading mode 'webtoon' and is_hidden set to 0

#### Scenario: DeleteSeriesCascadesToChapters
- **GIVEN** An existing series with associated chapters
- **WHEN** The series is deleted
- **THEN** All linked chapters are deleted via ON DELETE CASCADE

### Requirement: ChapterValidation

The system SHALL validate Chapter according to these rules:
- series_id and chapter_number must be unique together (UNIQUE(series_id, chapter_number))
- series_id must reference an existing series id
- chapter_number must not be null
- is_bookmarked defaults to 0 and cannot be null

#### Scenario: PreventDuplicateChapterNumbersInASeries
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** An existing chapter with chapter_number X for series Y
- **WHEN** Attempting to insert another chapter with the same series_id Y and chapter_number X
- **THEN** The insertion fails due to the unique constraint

#### Scenario: DeleteChapterCascadesToProgress
- **GIVEN** A chapter with existing reading progress
- **WHEN** The chapter is deleted
- **THEN** The associated progress record is deleted via ON DELETE CASCADE

### Requirement: ProgressValidation

The system SHALL validate Progress according to these rules:
- chapter_id must reference an existing chapter id and serves as primary key
- last_page_read cannot be null and defaults to 0
- is_completed cannot be null and defaults to 0

#### Scenario: TrackInitialChapterReading
- **GIVEN** An unread chapter
- **WHEN** A progress record is created
- **THEN** last_page_read defaults to 0 and is_completed defaults to 0

#### Scenario: UpdateReadingProgress
- **GIVEN** An existing progress record for a chapter
- **WHEN** A user reads a new page at a given time
- **THEN** last_page_read and last_read_at are updated
