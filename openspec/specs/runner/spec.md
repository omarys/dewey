# Runner Specification

> Generated by openlore v1.2.0 on 2026-10-07 15:05

## Purpose

Manages execution of the external Continuum reader process, constructing execution commands,
spawning reader sessions, and parsing exit progress payloads.

## Requirements

> `src/runner/continuum.rs`

### Requirement: BuildCommand

The system SHALL constructs the command line invocation for launching continuum with specified file, start page, reading mode, and optional storage profile flags.

#### Scenario: BuildCommandWithDefaultSettings
- **GIVEN** A chapter file path and starting page
- **WHEN** build_command is called without a specific reading mode
- **THEN** Command SHALL be configured with --file, --page, and default webtoon mode

#### Scenario: BuildCommandWithStorageProfile
- **GIVEN** A ContinuumRunner initialized with a storage profile
- **WHEN** build_command is called
- **THEN** Command MUST include the --storage-profile argument with the configured profile value

### Requirement: ParsePayload

The system SHALL parses the reader exit payload from stdout, extracting reading progress, completion status, and chapter-specific details with fallback handling.

#### Scenario: ParseValidJSONOutput
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** Stdout string containing a valid ContinuumExitPayload JSON representation
- **WHEN** parse_payload is called
- **THEN** Payload MUST be successfully deserialized into ContinuumExitPayload

#### Scenario: HandleEmptyStdoutFallback
- **GIVEN** Empty stdout output from reader process
- **WHEN** parse_payload is called with a fallback page
- **THEN** Payload SHALL return uncompleted status with the fallback page preserved

#### Scenario: ParseJSONEmbeddedInNoisyLogs
- **GIVEN** Stdout containing surrounding non-JSON log lines with a trailing JSON object
- **WHEN** parse_payload scans lines in reverse
- **THEN** Payload MUST find and deserialize the embedded JSON object

### Requirement: CompletionMessage

The system SHALL generates a celebratory or progress summary status message for the reader session based on payload state.

#### Scenario: CustomMessagePresent
- **GIVEN** An exit payload with an explicit message set
- **WHEN** completion_message is called
- **THEN** The explicit message MUST be returned

#### Scenario: ChapterCompletedCelebration
- **GIVEN** An exit payload where completed is true and no custom message is present
- **WHEN** completion_message is called
- **THEN** A chapter completion notification message SHALL be formatted

#### Scenario: ProgressSavedMessage
- **GIVEN** An exit payload where completed is false and no custom message is present
- **WHEN** completion_message is called
- **THEN** A progress message showing chapter number and current page SHALL be formatted

> `src/runner/labrador.rs`

### Requirement: SpawnInteractiveSelect

The system SHALL the runner must launch an interactive terminal process for the user to search and select a matching series, returning the chosen series url.

#### Scenario: UserSelectsAValidSeries
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** A valid series title and an accessible Labrador binary
- **WHEN** spawn_interactive_select is invoked
- **THEN** The interactive CLI process completes successfully and returns Some(url) containing the chosen
series URL

#### Scenario: UserCancelsSelection
- **GIVEN** A valid series title and an interactive selection prompt
- **WHEN** The user aborts or cancels the selection prompt
- **THEN** The process exits cleanly and returns Ok(None)

#### Scenario: ProcessExecutionFailure
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** The Labrador binary is missing or exits with a failure status
- **WHEN** spawn_interactive_select is invoked
- **THEN** An Err result is returned describing the execution failure

### Requirement: FetchSeriesChapters

The system SHALL the runner must execute the labrador cli in json output mode to fetch the full remote chapter list for a given series url.

#### Scenario: SuccessfulChapterListRetrieval
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** A valid series URL
- **WHEN** fetch_series_chapters is called
- **THEN** The CLI outputs JSON data and a parsed vector of LabradorChapterItem records is returned

#### Scenario: MalformedCLIOutputOrNetworkFailure
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** An invalid URL or unexpected CLI output format
- **WHEN** fetch_series_chapters is called
- **THEN** An Err result is returned indicating the failure to fetch or deserialize chapter data

### Requirement: ResolveBinary

The system SHALL the runner shall determine and return the resolved filesystem path for the labrador binary.

#### Scenario: ResolveConfiguredBinaryPath
- **GIVEN** A LabradorRunner initialized with a binary path
- **WHEN** resolve_binary is called
- **THEN** The PathBuf representing the binary path is returned


## Sub-components

> `LabradorRunner` is an orchestrator. Each sub-component below implements one logical block.

### Sub-component: CommandArg

> Implements: `cmd.arg`

Appends a command-line argument to the process command builder for Labrador CLI invocation.

#### Requirement: AppendArgument

The system SHALL the command builder must append the specified argument to its argument list.

#### Scenario: AddSubcommandFlag
- **GIVEN** An initialized Command builder for the Labrador CLI binary
- **WHEN** cmd.arg("--json") is called
- **THEN** The argument list MUST include "--json" in the invoked command

### Sub-component: ConfigureStdin

> Implements: `cmd.stdin`

Configures standard input handling for the external Labrador CLI subprocess.

#### Requirement: SetStdinConfiguration

The system SHALL the command builder shall set the standard input stream configuration for the spawned child process.

#### Scenario: ConfigurePipedStdinForInteractiveInput
<!-- openlore-test: priority=high (auto) -->
- **GIVEN** A command configured to execute an interactive Labrador prompt
- **WHEN** cmd.stdin(Stdio::piped()) is called
- **THEN** The child process stdin stream MUST be captured and accessible as a pipe

### Sub-component: ExecuteCommandStatus

> Implements: `cmd.status`

Executes the configured Labrador CLI subprocess and waits synchronously for its exit status.

#### Requirement: WaitExitStatus

The system SHALL the runner shall spawn the child process and block until it exits, returning the exit status result.

#### Scenario: SuccessfulCLIRun
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** A valid Command setup targeting the Labrador CLI binary
- **WHEN** cmd.status() executes to completion
- **THEN** An Ok variant containing the process ExitStatus MUST be returned

### Sub-component: CheckStatusSuccess

> Implements: `status.success`

Determines whether the Labrador process completed execution successfully with a zero exit code.

#### Requirement: VerifySuccessExitCode

The system SHALL the system must return true if the exit status code indicates clean execution with a zero exit code.

#### Scenario: ProcessExitedCleanly
- **GIVEN** An ExitStatus with exit code 0
- **WHEN** status.success() is evaluated
- **THEN** It MUST return true

### Sub-component: WrapOk

> Implements: `Ok`

Wraps a successful result value into the Ok variant of the standard Result type.

#### Requirement: ConstructOkResult

The system SHALL the function shall encapsulate the provided value into a result::ok variant.

#### Scenario: WrapParsedChapterMetadata
- **GIVEN** Successfully parsed chapter metadata records
- **WHEN** Ok(metadata) is evaluated
- **THEN** The return value MUST be Ok containing the metadata

### Sub-component: TrimContent

> Implements: `content.trim`

Removes leading and trailing whitespace from the provided output content string slice.

#### Requirement: StripContentWhitespace

The system SHALL the operation must strip all leading and trailing ascii and unicode whitespace from the content string slice.

#### Scenario: TrimRawOutputPayload
- **GIVEN** A content string with surrounding newlines and spaces " chapter list\n\n "
- **WHEN** content.trim() is evaluated
- **THEN** The output MUST equal "chapter list"

### Sub-component: WrapSome

> Implements: `Some`

Encapsulates a concrete value within the Some variant of an Option enum.

#### Requirement: ConstructOptionSome

The system SHALL the operation shall produce an option::some containing the supplied value.

#### Scenario: WrapExtractedIdentifier
- **GIVEN** A valid extracted series ID string
- **WHEN** Some(series_id) is evaluated
- **THEN** The result MUST be Option::Some containing the ID

### Sub-component: CheckTrimmedStartsWith

> Implements: `trimmed.starts_with`

Verifies whether a trimmed string begins with a specified prefix substring.

#### Requirement: CheckPrefix

The system SHALL the operation shall return true if the trimmed string starts with the specified prefix pattern.

#### Scenario: CheckForMetadataMarker
- **GIVEN** A trimmed string "[METADATA] Chapter 1"
- **WHEN** trimmed.starts_with("[METADATA]") is invoked
- **THEN** It MUST return true

### Sub-component: UnwrapOrDefaultQuery

> Implements: `query.unwrap_or`

Resolves an optional query parameter by extracting its inner value or falling back to a default value.

#### Requirement: ResolveOptionalQuery

The system SHALL the function must return the contained query string if option is some, or the fallback default if option is none.

#### Scenario: FallbackToEmptyQueryString
- **GIVEN** An option variable `query` with value None
- **WHEN** query.unwrap_or("") is invoked
- **THEN** It MUST return ""

### Sub-component: TrimmedToString

> Implements: `trimmed.to_string`

Allocates an owned String copy from a borrowed trimmed string slice.

#### Requirement: AllocateOwnedString

The system SHALL the operation shall convert the borrowed string slice into an independently allocated heap string.

#### Scenario: CreateOwnedToken
<!-- openlore-test: priority=high tags=smoke (auto) -->
- **GIVEN** A borrowed string slice `"series-42"`
- **WHEN** trimmed.to_string() is called
- **THEN** An owned String with identical text content MUST be returned

### Sub-component: SplitRawStdoutLines

> Implements: `raw_stdout.lines`

Creates an iterator yielding consecutive lines from the raw stdout output string.

#### Requirement: IterateLines

The system SHALL the method shall iterate over substrings split by newline delimiters (\n or \r\n) from the standard output.

#### Scenario: SplitMultilineCLIOutput
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** A raw stdout string containing "line1\nline2\nline3"
- **WHEN** raw_stdout.lines() is called
- **THEN** The iterator MUST yield "line1", "line2", and "line3" successively

### Sub-component: TrimLine

> Implements: `line.trim`

Strips whitespace characters from both ends of an individual line of CLI output.

#### Requirement: StripLineWhitespace

The system SHALL the operation must remove all leading and trailing whitespace characters from the line slice.

#### Scenario: TrimLineWithTrailingCarriageReturnOrSpace
- **GIVEN** A line string " item 10 "
- **WHEN** line.trim() is invoked
- **THEN** The returned slice MUST equal "item 10"

### Sub-component: CheckTrimmedEndsWith

> Implements: `trimmed.ends_with`

Checks if the trimmed string slice ends with a specific suffix pattern.

#### Requirement: CheckSuffix

The system SHALL the operation shall evaluate whether the end of the trimmed string matches the given suffix pattern.

#### Scenario: MatchURLFileExtension
- **GIVEN** A trimmed string "https://example.com/chapter.json"
- **WHEN** trimmed.ends_with(".json") is evaluated
- **THEN** The returned boolean MUST be true

### Sub-component: FindSubstringInTrimmed

> Implements: `trimmed.find`

Searches for the first byte position of a pattern within the trimmed string slice.

#### Requirement: FindPatternPosition

The system SHALL the function must return some(usize) representing the starting byte index of the pattern if present, or none if absent.

#### Scenario: LocateDelimiterInKeyValueRow
- **GIVEN** A trimmed line "Key: Value"
- **WHEN** trimmed.find(": ") is called
- **THEN** The returned value MUST be Some(3)

### Sub-component: StripTrimmedPrefix

> Implements: `trimmed.strip_prefix`

Removes a specific leading prefix from the trimmed string if present.

#### Requirement: RemovePrefix

The system SHALL the function shall return some(&str) containing the remaining slice without the prefix if matched, or none otherwise.

#### Scenario: StripLabelPrefix
- **GIVEN** A trimmed line "id: 12345"
- **WHEN** trimmed.strip_prefix("id: ") is called
- **THEN** The returned value MUST be Some("12345")

### Sub-component: TrimUrlString

> Implements: `url_str.trim`

Sanitizes an extracted URL string slice by trimming outer whitespace characters.

#### Requirement: CleanUrlWhitespace

The system SHALL the operation must strip leading and trailing whitespace from the candidate url string.

#### Scenario: CleanExtractedRemoteEndpoint
- **GIVEN** A URL string with padding " https://api.labrador.local/series "
- **WHEN** url_str.trim() is called
- **THEN** The resulting string slice MUST equal "https://api.labrador.local/series"

### Sub-component: ReplaceSeriesTitlePattern

> Implements: `series_title.replace`

Replaces all occurrences of a target pattern within a series title with replacement text.

#### Requirement: SubstituteTitleCharacters

The system SHALL the method shall generate a new string where every match of the target substring pattern is substituted by the replacement string.

#### Scenario: SanitizeTitleSeparatorCharacters
- **GIVEN** A series title "Title / Part 1"
- **WHEN** series_title.replace("/", "-") is invoked
- **THEN** The returned String MUST equal "Title - Part 1"
