# Agent Guidelines

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues (`omarys/dewey`). See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default five canonical triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout (`CONTEXT.md` + `docs/adr/` at the root). See `docs/agents/domain.md`.
